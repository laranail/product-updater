# Contributing

Where this file is silent, the [laranail contributing guide](https://github.com/laranail/.github/blob/HEAD/CONTRIBUTING.md) applies.

Thanks for contributing to `laranail/product-updater`.

- Discuss substantial changes in an issue first.
- `composer format` (Pint) for style; `composer test` (Pest) must stay green.
- Commits are authored under your own git identity.
